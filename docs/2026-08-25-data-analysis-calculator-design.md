# 公考资料分析计算器设计

## 目标

使用 Python、PySide6 和 pyqtgraph 构建桌面计算器。首个功能围绕基期、现期和增长率：用户输入任意两个已知量，程序计算第三个量，并通过柱状图和日志展示结果。

## 技术方案

- 使用 Python 作为开发语言。
- 使用 PySide6 构建桌面界面。
- 使用 Qt Designer `.ui` 文件描述布局，并通过 `QUiLoader` 在运行时加载。
- 使用 pyqtgraph 绘制基期和现期柱状图。
- 将计算逻辑、窗口交互和图表绘制拆分为独立模块。

## 项目结构

```text
公考计算器/
├─ Calculate.py
├─ calculator_window.py
├─ calculator_engine.py
├─ chart_widget.py
├─ ui/
│  └─ calculator.ui
├─ tests/
│  └─ test_calculator_engine.py
└─ requirements.txt
```

- `Calculate.py`：创建 `QApplication`，加载并显示主窗口。
- `calculator_window.py`：加载 `.ui`，连接信号，管理输入状态、按钮和日志。
- `calculator_engine.py`：实现公式和数据校验，不依赖 Qt。
- `chart_widget.py`：封装 pyqtgraph 图表创建、更新和清空。
- `ui/calculator.ui`：定义窗口布局与标准 Qt 控件。
- `tests/test_calculator_engine.py`：测试公式和边界条件。

## 界面布局

窗口初始尺寸约为 `1000 × 700`，支持缩放并设置合理的最小尺寸。

界面分为三个区域：

- 左上为图表区，占上半区宽度约 70%。
- 右上为输入操作区，占上半区宽度约 30%。
- 下方为日志区，横跨窗口，约占整体高度四分之一。

`.ui` 中的图表区使用普通容器占位。窗口加载后，由 Python 将 `pyqtgraph.PlotWidget` 插入该容器，不要求 Qt Designer 安装 pyqtgraph 插件。

右上区域包含基期、现期、增长率三个输入框。增长率旁固定显示 `%`，用户输入 `12` 表示 `12%`。该区域还包含“计算”和“清除”按钮。

日志区使用只读 `QTextEdit`，每次计算或错误追加一行；点击“清除”后清空全部历史。

## 计算规则

基本关系为：

```text
现期 = 基期 × (1 + 增长率 / 100)
```

由此得到三种计算：

```text
现期 = 基期 × (1 + 增长率 / 100)
基期 = 现期 ÷ (1 + 增长率 / 100)
增长率 = (现期 ÷ 基期 - 1) × 100
```

结果统一显示两位小数，内部计算不提前截断精度。

## 输入状态

- 少于两个非空输入时，三个输入框均可编辑。
- 恰好两个输入框有值时，自动锁定第三个空输入框，并以浅灰背景标识待计算项。
- 若用户删除一个已知值，原先锁定的输入框立即恢复编辑。
- 点击计算且已知量不足两个时，在日志提示“请输入两个已知量”。
- 正常操作不会允许用户主动填满三个输入框；若因粘贴或状态切换出现三个输入值，则拒绝计算并提示“请只输入两个已知量”。
- 结果写入后，窗口记录哪个字段是计算结果。此时三个框均有值，但不会被当作输入冲突。
- 用户修改任一已知值时，旧计算结果自动清空，剩余空框重新进入待计算状态。
- 点击“清除”后，三个输入框、日志和图表全部清空，所有输入框恢复可编辑。

## 数据校验

- 基期和现期支持整数或小数，但不得小于 `0`。
- 增长率支持整数、小数和负数。
- 基期为 `0` 时，不能通过基期和现期反推增长率。
- 通过现期和增长率反推基期时，增长率不得为 `-100%`。
- 无法解析的文本、非有限数值和公式无定义的情况均视为错误。
- 错误不使用模态弹窗；在日志中追加红色错误信息，并且不更新图表。

## 图表设计

图表采用“双柱 + 增长率标注”方案：

- 两根柱子分别表示基期和现期，只比较同一量纲的数据。
- 柱顶显示两位小数的具体数值。
- 图表上方显示增长率文字。
- 正增长显示 `↑ 增长 12.00%`。
- 负增长显示 `↓ 下降 8.00%`。
- 零增长显示 `— 持平 0.00%`。
- 图表提供简洁的坐标轴和网格，并随窗口缩放。

## 日志设计

成功计算后追加：

```text
计算完成：基期 100.00，现期 112.00，增长率 12.00%
```

错误日志使用红色文字，成功日志使用普通文字。日志保留本次运行中的多次计算记录，直到用户点击“清除”。

## 测试与验收

计算模块的单元测试覆盖：

- 输入基期和增长率计算现期。
- 输入现期和增长率计算基期。
- 输入基期和现期计算增长率。
- 正增长、负增长和零增长。
- 两位小数显示所需的舍入行为。
- 零基期、`-100%`、负的基期或现期、非法文本和非有限数值。

界面验证覆盖：

- 程序能够启动并正确加载 `.ui`。
- 上方左右布局比例约为 `7:3`。
- 输入两个值后第三个框自动锁定。
- 删除已知值后输入状态正确恢复。
- 修改已知值后旧结果自动失效。
- “计算”更新结果、图表和日志。
- “清除”重置三个输入框、图表和日志。
